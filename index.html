      Keydraw shortcuts

      • s — shape menu (r rect / s square / c circle / d diamond / a arrow / t text)
      • Click — select. Shift+Click — multi-select. Drag empty — marquee select.
      • Esc — deselect / cancel.
      • t — edit text. c — color. i — image fill. x — clear image.
      • l — cycle line style (solid/dashed/dotted). w — cycle width. b — toggle bidirectional arrow.
      • + / - — connector count. ] / [ — bring front / send back.
      • Shift+Arrows — move by size+25%. Arrows — nudge. g — toggle grid snap.
      • ⌘Z / ⌘⇧Z — undo / redo. ⌘C/⌘V — copy/paste. ⌘D — duplicate.
      • ⌘G — group. ⌘⇧U — ungroup. ⌘⇧H — horizontal layout. ⌘⇧J — vertical layout. ⌘⇧G — grid layout.
      • ⌘+Arrows — navigate to nearest object in that direction.
      • Scroll — zoom. Space+drag — pan. ⌘=/-/0 — zoom in/out/reset.
      • Delete — delete selected. ? — toggle this panel.
      • New shapes auto-connect via arrow when placed with a selection.
      • Auto-saves to browser. Use toolbar for JSON export/import and PNG/SVG export.
